# 大富豪（Daifugo）v0.1

公開URL: https://yoshisuke1111-svg.github.io/element-maze1/daifugo/

## モード
- **CPU対戦**: 4人。プレイヤー1人とCPU3人。CPUの強さは1〜100で調整
- **オンライン対戦**: 部屋主が招待URLを発行し、後から1〜3人が参加できる方式。開始前に席を確保した後、部屋主が「対局を開始」を押します。空席はCPUが担当します。部屋主が先手の座席（0番）を使用
- 新規参加は対局開始前に限ります。途中切断者は同じブラウザの保存された再接続用チケットで復帰できます。未接続の手番は一定時間後CPUが代行します
- 部屋主のページを閉じると部屋は終了します。現在、対局履歴はサーバー保存されません

## 採用ルール
カードの強さは3、4、…、10、J、Q、K、A、2、ジョーカー。階段は同一スートの3枚以上（ジョーカーは欠番に使えます）。パスするとその場が流れるまで復帰できません。上がった順で大富豪・富豪・貧民・大貧民を決定します。

ルール設定: ジョーカー枚数0〜2、革命（自然4枚組）、8切り、縛り、階段、11バック、階段革命（ジョーカーなしの5枚以上）、スペード3返し、次局の順位に応じたカード交換。8切り・11バック判定は実際に8/Jのカードが含まれる場合です。

次局の順位交換は簡易方式で自動実施します。大富豪と大貧民は2枚、富豪と貧民は1枚交換し、上位側は弱いカード、下位側は強いカードを差し出す仕様です。初期版では上位側が返すカードを自由選択する機能はありません。

## 通信
GitHub Pages の静的なHTML/JavaScript、PeerJS v1.5.5、WebRTCデータチャネルで通信します。部屋主が全カードと手番を管理し、参加者には各自の手札と公開される盤面情報のみを送信します。参加者からの着手は部屋主が合法手を検証します。第三者への部屋一覧公開やマッチングはありません。通信が成立するかはネットワーク条件と無料のシグナリングサービスに依存します。

WebRTCでは相手に接続情報（IPアドレス等）が見える場合があるため、知っている相手との利用を想定します。

## 技術とテスト
- `game.js`: カード配布、合法手、CPU、順位交換、座席別公開情報
- `app.js`: モバイルUI、CPU進行、招待URL式の部屋
- `index.html`: レスポンシブなテーブルとカード
- `test-engine.cjs`: 純粋なルール、順位、秘匿情報のテスト
- `test-browser.cjs`: ChromeによるCPU対局・複数ブラウザでの実際の参加と着手同期テスト
- `.github/workflows/daifugo-tests.yml`: 自動実行

他ゲームのディレクトリに手を加えず、独立した `daifugo/` に実装しています。
