# 大富豪（Daifugo）v0.1

公開URL: https://yoshisuke1111-svg.github.io/element-maze1/daifugo/

## モード
- **CPU対戦**: 2〜6人。最初の画面で名前を入力した後、対局人数・最初の手札枚数・ローカルルールを選んで開始します。CPUの強さ設定は一般画面には設けず、将来の管理画面で扱う予定です。
- **オンライン対戦**: 部屋主が3〜16文字のコードを決めて部屋を作成し、後から同じコードを入力した人が参加します。作成後の待機画面で部屋主が人数（2〜6人）、最初のカード枚数（1〜13枚。デッキと人数に応じて上限が下がる）、ジョーカー枚数、ローカルルールを選択します。空席はCPUが担当します。部屋主が0番席を使用します。
- 新規参加は対局開始前に限ります。途中切断者は同じブラウザの保存された再接続用チケットで復帰できます。未接続の手番は一定時間後CPUが代行します
- 部屋主のページを閉じると部屋は終了します。現在、対局履歴はサーバー保存されません

## 採用ルール
カードの強さは3、4、…、10、J、Q、K、A、2、ジョーカー。階段は同一スートの3枚以上（ジョーカーは欠番に使えます）。パスするとその場が流れるまで復帰できません。上がった順で大富豪・富豪・貧民・大貧民を決定します。

ルール設定: ジョーカー枚数0〜2、革命（自然4枚組）、8切り、縛り、階段、11バック、階段革命（ジョーカーなしの5枚以上）、スペード3返し、次局の順位に応じたカード交換。8切り・11バック判定は実際に8/Jのカードが含まれる場合です。

### ON/OFF可能な追加ローカルルール
- **5飛ばし**: 5を出した枚数分、次の参加者の手番を飛ばす
- **6戻し**: 6を出すと、その場が流れるまで数字の強弱が反転（通常の革命とは別）
- **7渡し**: 7を出した枚数分、次の参加者に渡す手札を自分で選択する。渡した結果上がる場合もあります
- **9リバース**: 9を出すと手番の回る向きが反転し、次の場以降も継続
- **10捨て**: 10を出した枚数分、手札から捨てるカードを自分で選択する
- **都落ち**: 前回の大富豪が次の対局で最初に上がれなかった場合、最後の順位になる

7渡しと10捨ては出した枚数分を選ぶ方式です。最後のカードを出して上がる場合には追加効果を行いません。地域差のあるルールなので、**ここでは上記の定義で実装**しています。

次局の順位交換は簡易方式で自動実施します。最上位と最下位で最大2枚、それ以外は上位・下位の対応ペアで1枚ずつ交換します。上位側は弱いカード、下位側は強いカードを差し出す仕様です。初期版では自由選択する機能はありません。

## 通信
GitHub Pages の静的なHTML/JavaScript、PeerJS v1.5.5、WebRTCデータチャネルで通信します。部屋主が全カードと手番を管理し、参加者には各自の手札と公開される盤面情報のみを送信します。参加者からの着手は部屋主が合法手を検証します。第三者への部屋一覧公開やマッチングはありません。コードの規則は人狼ゲームと同様で、文字・数字・ハイフン・アンダースコアを使い、NFKC正規化・空白除去・大文字化を行います。コードの衝突は通信サービス側で検出し、同じコードで二重作成した場合はエラーを表示します。招待URLの発行は行いません。通信が成立するかはネットワーク条件と無料のシグナリングサービスに依存します。

WebRTCでは相手に接続情報（IPアドレス等）が見える場合があるため、知っている相手との利用を想定します。

## 技術とテスト
- `game.js`: カード配布、合法手、CPU、順位交換、座席別公開情報
- `app.js`: モバイルUI、名前はトップ画面、部屋設定は作成後の待機画面、CPU進行、任意コードによる部屋作成・入室
- `index.html`: レスポンシブなテーブルとカード
- `test-engine.cjs`: 純粋なルール、順位、秘匿情報のテスト
- `test-browser.cjs`: ChromeによるCPU対局・複数ブラウザでの実際の参加と着手同期テスト
- `.github/workflows/daifugo-tests.yml`: 自動実行

他ゲームのディレクトリに手を加えず、独立した `daifugo/` に実装しています。

## 部屋設定の共有
部屋主が人数・手札枚数・ルールを変更すると、待機中の参加者にも反映されます。入室人数より少ない人数には設定できません。開始後はルールが固定されます。
配布するカード枚数を少なくした場合、使わないカードは配らずゲームから除外します。ジョーカーは設定枚数だけ配布されます。CPU強度の公開設定や管理画面はまだありません。
