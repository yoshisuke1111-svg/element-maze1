# 棋道 SHOGI LAB v0.4

公開ページ: https://yoshisuke1111-svg.github.io/element-maze1/shogi-v04/

## CPU
- 強さ1〜100を選べます
- 強さ80以上で、動作条件を満たすブラウザでは Fairy-Stockfish（WebAssembly）による思考を優先します
- 強いCPUの思考時間は2〜30秒で調節できます
- 端末・ブラウザが非対応の場合は軽量CPUに切り替え、「AI動作状態」に表示します
- ぴよ将棋Lv30への勝ち越しは未検証です

## 対局
- 棋譜表示、直前のCPUの手の矢印・色分け、成り・持ち駒・基本的な反則判定
- オンラインの人対人戦ではありません
- 対局データは端末内に保存されます。サーバーのアカウントやチップ決済はありません

## デバッグ時に教えてほしいこと
- CPUの難易度、思考時間、実際に使用されたAI（「AI動作状態」）
- OS・ブラウザ・端末
- 不自然な着手と、可能なら棋譜・スクリーンショット
- フリーズやエラーが起きた手数
