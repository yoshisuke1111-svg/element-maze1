# 将棋 v0.5 — コード式オンライン対局室

公開入口: https://yoshisuke1111-svg.github.io/element-maze1/shogi/
直接入口: https://yoshisuke1111-svg.github.io/element-maze1/shogi-v05/online.html

## 入室
1. 「オンライン対局」から「部屋を作る」へ進み、部屋主が任意のコードを入力して「部屋を作成」を押します。
2. 参加者は同じページの「部屋に参加」へ進み、**同じ部屋コード**を入力して入室します。
3. コードの規則は人狼ゲームに合わせています。**3〜16文字**、Unicodeの文字・数字・ハイフン・アンダースコアを使用できます。全角英数字の正規化、空白の除去、大文字化を行います。
4. 同じコードで既に別の部屋主が待機している場合、後から同じコードで部屋作成はできません。
5. 部屋主が先手、参加者が後手です。先に入室した部屋主が待機し、参加者が入った時点で対局を始められます。

今は**オープン部屋一覧やランダムマッチングはありません**。招待リンクの発行も行いません。

## 持ち時間と表示
- 部屋主が部屋作成時に、持ち時間なし・3分・5分・10分・15分から選択します。
- 接続後、双方の残り時間を表示し、指している側の時計だけを減らします。秒読みや加算時間は今の版ではありません。
- 時間切れは負けとして処理され、両端末の盤面中央に勝敗が大きく表示されます。
- 部屋主の端末が時計と盤面状態を管理し、相手の端末へ同期します。通信が切れた間は時計を一時停止し、再接続後に再開します。
- 持ち駒には駒の形の絵・駒名・枚数を表示します。
- CPU対戦の持ち時間は v0.4 で選択できます。CPUの「思考時間」と「双方の持ち時間」は別の設定です。

## 技術
- PeerJS Cloud のシグナリングと WebRTC による1対1通信です。常設の部屋を保持するサーバーではありません。部屋主がページを閉じると終了します。
- PeerJS の接続用IDは、ユーザーが入力した正規化コードをSHA-256で変換して作成します。ページURLの末尾にコードを出す必要はありません。
- 対局ルール、成り、持ち駒、投了と着手同期はこれまでのv0.5から継承します。CPU対局はv0.4に残ります。
- 途中切断した参加者は同じブラウザの接続チケットを用いて、部屋コードで再接続できます。
- 同じコードを知っている人は接続できるので、他人に知られにくいコードを使ってください。
- 通信ネットワークの制限やPeerJS Cloud側の状態によっては接続できないことがあります。
