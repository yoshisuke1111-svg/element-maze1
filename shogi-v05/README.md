# 棋道 v0.5 — フリー対局室（オンライン将棋）

公開URL: https://yoshisuke1111-svg.github.io/element-maze1/shogi-v05/

## 利用方法
1. 「友達とオンライン対局」→「フリー対局室を作る」を開き、任意の表示名を入力します。
2. 部屋を作るとランダムな招待URLが発行され、部屋主が先手として待機します。
3. 友達が招待URLを開くと自動的に後手として入室し、将棋盤が共有されます。
4. 一手指すごとに相手の盤にも反映されます。成り／不成り、持ち駒、二歩、打ち歩詰め、王手放置の基本判定に対応します。
5. 終局後は部屋主が「もう一局」を押すことで再戦できます。

## 仕様と制限
- 1部屋2人。招待URLの知識が入室の条件です。ログイン、対局料、チップ機能はありません。
- GitHub Pagesの静的サイトで、通信にはMITライセンスのPeerJSクライアントと無料のPeerJS Cloud接続仲介、WebRTCデータチャネルを利用しています。
- 部屋主がタブを閉じる／更新すると部屋が消えます。サーバー保存はありません。
- 参加者が途中で切断した場合は同じURLから再接続できます。端末内の再接続用チケットが一致する必要があります。
- 通信環境（NAT、フィルタ、無料仲介サービスの状態等）によっては接続できない場合があります。無償の試験機能であり稼働率保証はありません。
- WebRTC通信では相手の接続情報（IPアドレスなど）が相手側に見える場合があります。信頼できる相手との対局用です。
- URLは十分ランダムに生成され、部屋主が待機している間だけ有効です。
- デバッグ時には利用した端末・ブラウザ、エラー表示、指し手、通信状況を記録してください。
- CPUとの対局は v0.4 の専用ページへ移動する設計です。
